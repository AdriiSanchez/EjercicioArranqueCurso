# Gestor de Tareas (To-Do) - Consola Java

Pequeña aplicación de consola desarrollada en Java para el ejercicio de arranque de curso (2DAM). Permite gestionar una lista de tareas de forma interactiva mediante un menú de texto.

## Características
El programa cumple con las siguientes historias de usuario:
- Añadir una nueva tarea con su descripción.
- Ver la lista de tareas pendientes.
- Marcar una tarea específica como completada.
- Eliminar una tarea de la lista.

## Cómo ejecutar el programa

**Desde IntelliJ IDEA:**
1. Clona este repositorio o abre la carpeta del proyecto en IntelliJ IDEA.
2. Abre el archivo `Main.java`.
3. Haz clic en el botón verde de "Play" (`Run 'Main.main()'`) situado junto a la declaración de la clase o el método `main`.
4. Interactúa con el menú directamente desde la consola integrada del IDE introduciendo los números de las opciones.

**Desde la terminal:**
1. Navega hasta el directorio donde se encuentra `Main.java`.
2. Compila el código ejecutando: `javac Main.java`
3. Ejecuta el programa con: `java Main`
